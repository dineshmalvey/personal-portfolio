An ultra-modern, interactive, cyberpunk-inspired web portfolio and live resume replica for **Dinesh Malvey** (Senior Data Analyst | Market Research, Business Intelligence & Process Automation).

## ✨ Features & Interactivity

- **🌌 Moving Background Engine:** High-performance, mouse-interactive 3D particle neural constellation canvas that responds dynamically to cursor movements and window dimensions.
- **🎨 Multi-Theme Cyber HUD:** 
  - **Cyan Cyber** (Electric Cyan & Neon Violet)
  - **Synth Violet** (Cyber Magenta & Azure)
  - **Matrix Emerald** (Matrix Green & Deep Cyber Blue)
- **🔊 Synthesized Sci-Fi Audio FX:** Built-in Web Audio API synthesizer that produces subtle, tactile futuristic clicks, chirps, and hover tones with zero external audio dependencies. Includes one-click audio mute/unmute control.
- **💻 Interactive Command Line Terminal (CLI):** Fully operational simulated terminal where recruiters and visitors can enter commands (`help`, `summary`, `skills`, `experience`, `impact`, `innovations`, `contact`, `theme`, `matrix`, `clear`) or tap quick-action chips.
- **🧪 Interactive Innovation Lab:**
  - **Account Matcher Simulator:** Live demonstration of Dinesh's RapidFuzz & ML Sentence-Transformer matching logic that elevated match accuracy from 5–10% to 70%+.
  - **500k+ Contact Search Benchmark:** Visual performance comparison showing the leap from a 2-hour manual lookup to sub-5 minutes.
  - **Autonomous Salesforce Enrichment Pipeline:** Flow architecture telemetry showing ZoomInfo API + LLM integration.
  - **Executive BI KPI Controller:** Interactive metric dashboard switcher for Marketing ROI, CPL, CAC, and Event Recovery.
- **💼 Complete Resume Experience:** Every single bullet point, metric, company, skill category, degree, and language from your resume is accurately rendered and emphasized.
- **🖨️ One-Click Clean Resume PDF Export:** Includes a tailored `@media print` layout that automatically strips all HUD chrome and formats as an executive, crisp resume when clicking **"EXPORT RESUME"** or using `Ctrl+P`.

## 🌐 Deploying to GitHub & GitHub Pages (Step-by-Step)

Follow these simple steps to publish this portfolio online for free on GitHub Pages:

### Step 1: Open Terminal in the Project Directory
Open PowerShell or Command Prompt and navigate to your project folder:
```powershell
cd "C:\Users\dines\OneDrive\Documents\GitHub\dinesh-malvey-interactive-resume"
```

### Step 2: Initialize Git and Commit
```powershell
git init
git add .
git commit -m "Initial commit: Dinesh Malvey futuristic interactive portfolio"
```

### Step 3: Create a Repository on GitHub
1. Go to [GitHub.com](https://github.com) and click **New Repository** (or visit https://github.com/new).
2. **Repository name options**:
   - Option A (Personal Site URL): Name it `dineshmalvey.github.io` (Replace with your actual GitHub username). Your site will be published at `https://dineshmalvey.github.io/`.
   - Option B (Project URL): Name it `portfolio` or `interactive-resume`. Your site will be published at `https://<username>.github.io/<repo-name>/`.
3. Set the repository to **Public**.
4. Leave "Add a README file" unchecked (you already have this one).
5. Click **Create repository**.

### Step 4: Link and Push to GitHub
Run the following commands in your terminal (replace `<YOUR_GITHUB_USERNAME>` and `<REPO_NAME>` with your details):
```powershell
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<REPO_NAME>.git
git push -u origin main
```

### Step 5: Enable GitHub Pages (Instant Hosting)
1. On your GitHub repository page, click **Settings** (gear icon in the top tabs).
2. In the left sidebar, click **Pages** (under the "Code and automation" section).
3. Under **Build and deployment > Source**, select **Deploy from a branch**.
4. Under **Branch**, select `main` and keep the folder as `/ (root)`.
5. Click **Save**.

🎉 Within 1 to 2 minutes, GitHub will generate your live public URL (e.g., `https://<YOUR_GITHUB_USERNAME>.github.io/<REPO_NAME>/`). You can now add this link directly to your LinkedIn headline, resume header, and email signature!
